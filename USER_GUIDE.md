# StyleSync — Quick User Guide

This short guide explains, in simple steps, how to use StyleSync as an end user.

1) Sign in
- Open the app and sign in using the Sign In button. If you are not signed in, some features will redirect you to the sign-in page.

2) Create a profile (two easy ways)
- Essays (recommended):
  - Go to "Create Your Writing Style" → "Upload Essays".
  - Paste one or more short writing samples (1–3 paragraphs each).
  - Click "Analyze Style" and then "Create Profile" to save.
- Quick questionnaire:
  - Choose "Answer Questions", move the sliders and pick a tone.
  - Click "Complete Questionnaire" then "Create Profile" to save.

3) Start paraphrasing
- Go to the Paraphrase page.
- Select your active profile (if not selected automatically).
- Paste the text you want rewritten and run the paraphrase.

4) Use the Writing Guide
- Open the Writing Guide to see two tabs: "Essay Analysis" and "Writing Lessons".
- If your profile includes a real essay, Essay Analysis shows personalized feedback and metrics.
- Writing Lessons provides short, actionable tips and examples you can apply immediately.

5) Saving and syncing
- Give your profile a name before saving (e.g., "Casual Blog Style").
- Profiles save locally and sync to the server when you are signed in.

6) Quick troubleshooting (what to try first)
- Nothing happens when saving: make sure you entered a profile name and signed in.
- No essay analysis: confirm you pasted at least one essay and clicked "Analyze Style".
- Paraphrase seems off: try adding one sample essay for better accuracy.

7) How to report a problem (easy)
- Take a screenshot of the issue (Windows: `Win+Shift+S`) and note the page where it happened.
- If there is an error message, copy the text and include it.
- Attach the screenshot and the profile name (if any) and send to support.

That's it — the app is designed to be simple: create a profile, paraphrase, and use the Writing Guide to improve.

## How to Share Files for Support (for non-developers)

If you need to send files or app information to support or a developer, follow these simple steps — no coding required.

1. Describe the problem briefly
  - What you expected to happen and what actually happened.
  - The steps you took (which page you opened, what you clicked).

2. Take a screenshot or short recording
  - Windows: press `Win+Shift+S` to capture a screenshot. Use Xbox Game Bar (`Win+G`) for short clips.
  - Save the image/video and attach it to your message.

3. Copy any error text
  - If you see an error popup, copy the text and paste it into your message.
  - To capture browser console errors: open the browser, press `F12` (or `Ctrl+Shift+I`) → Console, then copy any red errors.

4. Include profile details (if applicable)
  - Note the profile name and when you created it. If the app has an "Export" or "Share" button on the profile page, use it and attach the exported file.

5. Zip multiple files (optional)
  - To send several screenshots/files together: select them, right-click → Send to → Compressed (zipped) folder (Windows).

6. Upload and share
  - Attach files directly to an email or support form.
  - Or upload to a cloud storage link (Google Drive, Dropbox, OneDrive) and share the link.
  - For text-only items, use GitHub Gist: go to https://gist.github.com/, paste the text, create the gist, then share the link.

7. Add environment info
  - Your browser and version (e.g., Chrome 114), operating system (Windows 10/11), and the approximate time the issue happened.

8. Provide a short sample input (if relevant)
  - Paste one short paragraph (1–3 sentences) you used when the problem happened.

9. Send everything together
  - Include: short description, screenshots/video, error text, profile name (if any), cloud link or attachments, and steps to reproduce.
